# Resonator
A note-taking web application built with Flask and SQLAlchemy, featuring a markdown editor. Created for the final project of CS50x.

## Features
- Create, read, update, and delete notes
- Markdown support for rich text formatting
- Tag notes with comma-separated labels and filter by tag
- Responsive design, based on Pico.css

## Tech Stack
- **Backend**: Flask (Python)
- **Database**: SQLite
- **ORM**: SQLAlchemy
- **Frontend**: HTML/CSS (Pico CSS)
- **Markdown Editor**: EasyMDE
